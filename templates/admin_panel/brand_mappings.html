How brand mappings work

The schedule uses Brand names. Set LMRB Theme to match monitoring data (Advt_Theme / MapOnline Theme). Set TC Theme to match Transmission Certificate data (the product/ad name the channel uses in their TC file). One brand can have multiple mappings. Duration is optional — restricts the mapping to a specific ad length.
