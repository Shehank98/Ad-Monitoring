Expected Schedule File Format

The system auto-detects and converts both the agency pivot format (shown below) and the flat pre-processed format. Month and date range are detected automatically.

Key Rules

  • Header row must have PROGRAM or PROGRAMME column
  • Date columns must be actual date values in Excel (not text)
  • Section rows: COMMERCIAL BENEFITS or SPONSORSHIP BENEFITS (or BONUS COMMERCIALS)
  • Brand rows: have a name in Programme col but no Day/Time values
  • Spot count per date = number of individual ad spots on that date
